1. The Edge Dilemma

Modern mid-sized enterprises and college campuses manage thousands of heterogeneous endpoints (lab PCs, faculty systems, student laptops) branching from an Admin Router through departmental switches (Lab-1, Lab-2, Lab-3).

Hardware Bottleneck: Traditional security appliances (Suricata + Zeek + Elastic) demand 4–8 GB RAM and heavy CPU, crashing low-cost edge routers.
The False Positive Hazard: Naive rate-limiters block genuine students downloading research datasets, mistaking heavy volume for a cyber attack.
💡

2. Our Solution & Scope

SentinelEdge is an intelligent, low-overhead edge tap deployed directly at the main router management/SPAN port.

Sub-Millisecond Wire Inspection: Clean traffic forwarded with near-zero latency (< 0.4 ms).
Dual-Engine Gatekeeping: Snort/Suricata rules for deterministic CVEs + AI Agent & Neurons for zero-day behavioral anomalies.
Embedded Forensics: Zero-server SQLite WAL database + Wireshark PCAP generation.
🌐

4. The 4-Tier Autonomous Pipeline

Hierarchical triage ensuring deep compute is triggered only when required:

TIER 1 SURICATA & SNORT WIRE FILTER
Wire-speed .rules parsing, stateless flag checks (Xmas, NULL), and empty-port velocity thresholding. Clean flows bypass to destination immediately!
▼ (If Flagged / Ambiguous)
TIER 2 SENTINEL AI AGENT
Flow aggregator profiling Port Dispersion & Port Entropy. Distinguishes single-port heavy streams from multi-port scans. Normalizes 10-feature vector.
▼ (10-Feature Vector)
TIER 3 THE NEURONS (DNN)
Multi-Layer Neural Network (10 ➔ 32 ➔ 16 ➔ 5 Classes). Deep non-linear pattern matching trained on standardized CIC-IDS2017 flow distributions.
▼ (Classification Verdict)
TIER 4 AUTONOMOUS TRI-STATE RESPONSE
Forward: Clean or genuine heavy data.
Block & Jail: Terminate attacker IP with 90–120s cooldown.
Quarantine: @very suspicious anomaly deep forensic dump.
⚖️

7. Dynamic Jail & Forensic PCAP

Dynamic Firewall Jails (1-2 Min): When an attacker targets empty ports, their IP is immediately dropped. An active countdown timer (90s) protects the network from DDoS.
Automatic Expiry: Once cooldown expires without further threats, the IP is automatically released with zero manual admin intervention.
Wireshark-Ready Forensics: Generates real-time standard .pcap binaries of flagged packets for courtroom or incident response verification.
